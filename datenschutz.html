2. Welche Daten die App verarbeitet

Die App verlangt keine Registrierung und keine E-Mail-Adresse. Für ein Spielprofil wird ein frei gewählter Name eingegeben; dafür kann auch ein Spitzname verwendet werden. Zu diesem Profil speichert die App die Spielstände auf dem verwendeten Gerät. Ein Name und die zugehörigen Spielstände können einer Person zuordenbar sein, wenn jemand weiß, wer das jeweilige Profil nutzt. Die App greift nicht auf Standortdaten, Kontakte oder Fotos zu.

3. Keine Werbung und kein Tracking

Die App enthält keine Werbenetzwerke, keine Analyse- oder Trackingdienste und keine personalisierte Werbung. Es werden keine personenbezogenen Daten zu Werbezwecken weitergegeben.

4. Offline-Nutzung und lokale Speicherung

Der Profilname und die zugehörigen Spielstände werden im lokalen Speicher des Browsers auf dem verwendeten Gerät gespeichert. Das dient dazu, verschiedene Kinder auseinanderzuhalten und ihren jeweiligen Spielfortschritt beim nächsten Öffnen fortzusetzen. Diese Angaben werden nicht an mich oder andere Nutzer übertragen. Personen mit Zugang zu demselben Gerät können die dort gespeicherten Profile und Spielstände sehen. Ein Profil und seine Spielstände können in der App gelöscht werden. Andernfalls bleiben sie auf dem Gerät gespeichert, bis die entsprechenden Browser- oder App-Daten gelöscht werden.

Für die Offline-Funktion können App-Dateien zusätzlich im Browser-Cache gespeichert werden. Dadurch können Inhalte auch ohne aktive Internetverbindung bereitstehen.

5. Technische Bereitstellung über GitHub Pages

Die Web-Inhalte der App werden über GitHub Pages bereitgestellt. Beim technischen Abruf können durch den Hosting-Anbieter Verbindungsdaten verarbeitet werden, zum Beispiel IP-Adresse, Zeitpunkt des Abrufs und angeforderte Datei. Auf diese technische Verarbeitung durch GitHub habe ich keinen unmittelbaren Einfluss.

Weitere Informationen zur Datenverarbeitung durch GitHub finden sich in der Datenschutzerklärung von GitHub.

Der Kauf, Download und die Installation der App erfolgen über Google Play. Dabei verarbeitet Google die hierfür erforderlichen Konto-, Geräte- und Zahlungsdaten nach den eigenen Datenschutzbestimmungen. Ich erhalte keine vollständigen Zahlungsdaten wie Kreditkarten- oder Bankverbindungsdaten.
